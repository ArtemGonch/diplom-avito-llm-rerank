# BX UsedCars. Проверка базового скора по заданию от 12 ноября

На 18.11.2026 пересчитаны все десять метрик базового скора на исходном
фрагменте. Основной `NDCG_b0.8(target_contact_s_d7)` равен
**0,48385284659867683** на **18 из 1 000** поисковых групп. По составной
метке `target` получилось **0,4044839459186125** на **975** группах.
[Полные агрегаты](../results/current/metrics/avito_bx_usedcars_baseline_20261118.json).

## Структура данных

Источник — Parquet `bx_usedcars_text_test_1000_groups.parquet` и сопровождающий
README из папки диплома. Файл весит 13 245 668 байт, SHA-256 совпадает с README.
В файле 31 784 строки, 1 000 разных `serp_x`, 265 столбцов, 225 штатных
признаков и десять меток. В группе от 1 до 50 кандидатов, медиана 35.
`source_row_index` уникален. Все строки относятся к `Transport.UsedCars`.
Это пул кандидатов из офлайн TEXT test за 6–7 октября 2026 года по Москве.
`baseline_score` — сохранённая оценка базовой модели. Текст запроса пуст
или отсутствует у 1 499 строк. В файле есть идентификаторы и списки
событий результата, поэтому код публикует только агрегаты.

## Метрика и награды

Внутри каждой группы используем кандидатов с наблюдаемой меткой. NDCG —
сумма значений метки, умноженных на `0.8 ** rank`, делённая на идеальную
сумму с добавкой `1e-5`. Ранги начинаются с единицы, оценка использует весь
пул после маскирования. При равных скорах сохраняется порядок строк файла.
Группы с нулём наблюдаемых значений или с одинаковой меткой среди
наблюдаемых кандидатов пропускаются. Итог — среднее по пригодным группам.
В выгрузке равных базовых скоров внутри группы не оказалось.

- **Целевой контакт.** `target_contact_s_d7` принимает 0 или 1 на
  наблюдаемых строках. Всего 24 строки со значением 1 в 21 группе,
  из которых 18 имеют разные наблюдаемые метки. В 171 группе все метки
  отсутствуют, ещё в 811 наблюдаемые значения одинаковы.
  Все 24 положительные строки имеют `has_tc_events=1`, но такой флаг есть
  и у 172 строк с наблюдаемой меткой 0. Для NDCG следует брать готовую метку.
- **Составная метка.** `target` задана на всех строках. Во всех 31 784 строках
  наблюдается точное равенство `target = max(ux_target, tc_target)`.
  Сумма двух компонент совпадает с `target` только на 31 602 строках.
  Значения UX-компоненты — 0, 0.01, 0.025, 0.03, 0.05, 0.1, 0.15.
  Значения контактной компоненты — 0, 0.2, 1.
- **Прочие метки.** `contact_s`, `contact_s_d7`, `btc_s`, `fav_s`,
  `btc_wo_fav_s` и варианты с суффиксом `d7` также принимают 0 или 1
  на наблюдаемых строках. У каждой из девяти бинарных меток 12 207
  пропусков. Например, `contact_s_d7` дал 0,4882869209051207 на 138 группах.

Готовые значения меток достаточны для пересчёта. Точное соответствие
кодов событий и значений UX- и контактной компонент, правила атрибуции
и построения меток из событий требуют спецификации от владельца выгрузки.
Наблюдаемое равенство компонент описывает данный файл, его перенос
на другие даты следует проверять заново.

## Объём следующей выгрузки

При одинаковом составе столбцов средний размер составляет примерно
13,25 кБ на группу. **10 000 групп — около 132 МБ**, **24 000 — около 318 МБ**,
**92 939 — около 1,23 ГБ**. Это линейная оценка в десятичных единицах
по объёму текущего Parquet. Истории, атрибуты и мультимодальные файлы
потребуют отдельной оценки после пробного экспорта.

Для следующего пилота выбрать ориентир **12 000 групп для настройки и
12 000 для отдельного теста**. При наблюдаемой доле 1,8% это примерно
216 пригодных групп в каждой части. Число 200 пригодных групп — рабочий
ориентир, его достаточность для обнаружения эффекта пока неизвестна.
Фактические знаменатели надо посчитать после выгрузки. Временные части
зафиксировать заранее, отбор внутри них делать по ключу группы,
сохраняя всех кандидатов. При сравнении методов отдельно оценить
неопределённость разницы на одних и тех же тестовых группах. Запросы
финального теста хранятся отдельно от запросов, по которым настраиваются
промпты или параметры модели.

## Воспроизведение

```bash
python scripts/avito/evaluate_bx_baseline.py --input /path/to/bx_usedcars_text_test_1000_groups.parquet
python -m unittest -q tests/test_avito_bx_baseline.py
```

Скрипт требует PyArrow. Он сверяет размер и SHA-256, проверяет структуру
файла, вычисляет NDCG из строк и сверяет все десять средних с эталонными
агрегатами в метаданных. Максимальная разница **5,55 × 10⁻¹⁷** при
абсолютном допуске **10⁻¹²**, знаменатели совпали точно. Тесты покрывают
линейную награду, ранги с единицы, порядок при равных скорах, пропуски,
однородные группы и проверку метаданных.

Независимый ревьюер Astra xhigh повторил расчёт через ранги Pandas,
подтвердил все десять средних и знаменателей, проверил вывод о метках,
план объёма и состав публикуемых файлов.

Для персонального rerank ещё нужны время и тип взаимодействий до запроса
и атрибуты объявлений из истории и пула с совпадающими ключами. По 18
текущим группам можно проверить технический расчёт, итоговая оценка
улучшения зависит от отдельной тестовой выгрузки.
