# UsedCars. Разбор запроса и сравнение моделей

Локальный парсер возвращает `filters` и `unresolved`. Поля `start` и `end`
задают полуоткрытый диапазон индексов символов исходной строки. По нему можно
восстановить `evidence`. Словарный фильтр хранит пару `attr_id` и `value_id`.
Числовой хранит `min`, `max` и при необходимости признак строгой границы.
Это внутренний формат эксперимента. Для интеграции в Avito потребуется контракт
поискового API и таблица допустимых зависимостей атрибутов.

## Команды

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" parse 'автомат до 1,5 млн без ДТП'
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" serve --port 8782
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" packet --out reports/text2filter_annotation
```

Демо доступно по `http://127.0.0.1:8782/`. Входы, ответы моделей, веса и ручные
оценки остаются в игнорируемых каталогах. Примеры в интерфейсе синтетические.

Для небольшой локальной выборки можно запустить Qwen3-4B-4bit через MLX на
Apple Silicon. Модель получает до 20 вариантов, подтверждённых словарём или
числовым разбором с фрагментом исходного запроса. Вариант с коллизией ID
остаётся нерешённым. Выбор модели проверяется по списку вариантов. Возврат
парсера при ошибке модели имеет отдельный статус. При оценке такие запросы
входят в общую выборку с результатом парсера, число замен выводится отдельно.

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" teacher \
  --manifest reports/text2filter_annotation/sampling.jsonl --limit 50 \
  --qwen "$QWEN_WEIGHTS" --out reports/qwen_pilot.jsonl
```

Перед использованием псевдометок проверяющий сохраняет принятые строки со
статусом `reviewed`. Студент классифицирует пары «запрос, предложенный фильтр»
общим для обоих вариантов линкером. `--base` указывает на локальную копию
`cointegrated/rubert-tiny2`. Для контроля применяются одинаковые seed,
архитектура, порог 0,5 и число шагов. Для второго обучения добавляется
`--pseudo` с проверенными модельными строками. Обе версии требуют полных
80 исходных эталонных примеров из зафиксированного train.

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" train \
  --train reports/text2filter_annotation/train.csv \
  --manifest reports/text2filter_annotation/sampling.jsonl \
  --base "$RUBERT_WEIGHTS" --out checkpoints/text2filter_human
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" predict \
  --input reports/text2filter_annotation/test.csv \
  --student checkpoints/text2filter_human --out reports/text2filter_test_predictions.jsonl
python scripts/avito/text2filter.py score --gold reports/text2filter_annotation/test.csv \
  --predictions reports/text2filter_test_predictions.jsonl \
  --manifest reports/text2filter_annotation/sampling.jsonl
```

`predict` без модели запускает правила. `--qwen` даёт оценку прямого выбора
через Qwen на том же списке кандидатов. Оценка закрытого теста использует
полностью заполненную независимую эталонную разметку. Для макрооценки семейства взвешены
по обратной вероятности отбора, для оценки трафика вес дополнительно
умножен на частоту семейства. Представитель семейства отбирается с
вероятностью, пропорциональной его частоте. Задержку замеряем после
прогрева, без загрузки весов и индекса.

При оценке двух вариантов BERT используйте ту же разметку и одинаковые ID
запросов. Команда `compare` считает попарную разницу доли точных разборов
между вариантами и интервалы по 2 000 повторных выборок внутри страт.
Десять самых частых семейств входят в каждый повтор целиком. Интервалы
отражают неопределённость отбора при фиксированной разметке.

```bash
python scripts/avito/text2filter.py compare --gold "$TEST_REFERENCE" \
  --control "$BERT_CONTROL_PREDICTIONS" --augmented "$BERT_AUGMENTED_PREDICTIONS" \
  --manifest reports/text2filter_annotation/sampling.jsonl
```

Альтернативный источник эталона — слепая разметка от независимых экземпляров
GPT-6.2 Astra xhigh. В этом режиме измеряется совпадение с её разметкой на
реальных запросах. Версию модели-разметчика, объём повторной разметки и
согласие разметчиков фиксируют вместе с метриками.

Эксперимент от 25 ноября использует 80 эталонных train, 40 dev и 120 test.
На 30 тестовых запросах повторно сравнили наборы фильтров, совпали 27 из 30.
Для трёх расхождений использована отдельная слепая разметка Astra. Для одной
половины проверки взяли первую завершённую резервную разметку до подсчёта
метрик моделей. Из 80
проверенных обучающих ответов Qwen 34 совпали по набору фильтров с независимой
разметкой и вошли во второй BERT. Оба BERT дали одинаковые разборы на всех
120 запросах. [Агрегированные метрики](../results/current/metrics/avito_text2filter_astra_20261125.json).

## BERT v2 и разметка Qwen

Опция `--linker v2` расширяет список кандидатов. Она учитывает разговорные
названия, разное написание кодов моделей и проверяемые связи между марками
и моделями. Идентификаторы берутся из исходного словаря. Для отдельных
однозначных моделей марка и модель могут иметь один фрагмент текста.
Конфликтующие значения, отрицания и альтернативы сохраняются для уточнения.
Дубликаты ID одного атрибута остаются неоднозначными.

Для обучения используется тот же `rubert-tiny2`. В режиме `teacher --consensus`
Qwen получает один запрос с двумя инструкциями и прямым либо обратным порядком
вариантов. В обучение допускаются совпавшие наборы индексов, проверенные на
границах списка. Оба вызова использовали один Qwen, поэтому это псевдометки
с проверкой согласия. Для каждого класса половину батча v2 составляют пары из
эталонного набора, когда доступны оба источника. В контрольном обучении все
пары берутся из эталона. Общие параметры двух плеч — 300 шагов, тот же seed
и размер батча.

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v2 teacher \
  --input "$QWEN_TRAINING_QUERIES" --manifest "$RESERVED_FAMILIES" \
  --consensus --qwen "$QWEN_WEIGHTS" --out "$QWEN_OUTPUT"
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v2 train \
  --train "$ASTRA_TRAIN" --pseudo "$QWEN_CONSENSUS" --manifest "$RESERVED_FAMILIES" \
  --base "$RUBERT_WEIGHTS" --steps 300 --out "$BERT_V2"
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v2 predict \
  --input "$NEW_TEST_INPUTS" --student "$BERT_V2" --threshold "$DEV_THRESHOLD" \
  --out "$NEW_TEST_PREDICTIONS"
```

`QWEN_CONSENSUS` содержит только строки со статусом `qwen_consensus` из файла
учителя. Если правила предложений изменились после разметки, входы учителя
сверяют по полному упорядоченному списку вариантов и исключают затронутые.
Порог для основного сравнения двух v2 выбирается на control dev и затем
применяется к обоим. Отдельно можно зафиксировать порог v2 с Qwen по тому
же dev; это оценивает всю конфигурацию.

### Результат 26 ноября 2026 года

Слепая разметка GPT-6.2 Astra xhigh охватила 80 новых запросов. До оценки
исключили два семейства, которые оказались в старом пробном прогоне Qwen,
и пересчитали веса четырёх страт. На 15 повторно размеченных запросах из
оставшихся 78 совпали полные наборы фильтров. Использованы модели одного
семейства и общий порог 0,5, выбранный на dev. В dev исправили один ID по
исходному словарю до выбора порога.

Из 380 запросов с вариантами Qwen 287 дали одинаковый выбор с двумя
инструкциями. После проверки совпадения входов с версией линкера,
которая сохраняет конфликты, осталось 284 запроса. Среди их пар было
464 принятых и 20 отклонённых вариантов. В эталонном обучении было
101 принятое условие и две отрицательные пары. В слепом аудите 20 принятых
ответов наборы фильтров совпали с Astra в 6 случаях целиком и в 12 среди
доступных кандидатов. В этой проверке намеренно увеличена доля запросов,
где Qwen отклоняла часть предложений.

На одних и тех же 78 запросах доля полного совпадения наборов фильтров
по семействам выросла с 60,56% у прежнего BERT с Qwen до 67,89% у v2 с Qwen.
Контрольный BERT v2 на эталонных метках дал 68,26%. Добавка Qwen при
одинаковом линкере и пороге дала 0 побед, 75 ничьих и 3 проигрыша по
совпадению полного набора. С учётом частот запросов результаты составили
71,13%, 70,84% и 73,92% соответственно для v1 с Qwen, v2 с Qwen и v2
с эталоном. Новый генератор вариантов включал 74 из 100 эталонных фильтров,
прежний — 66. В парной оценке v2 с Qwen против v1 интервал по семействам
включал ноль. [Агрегаты и знаменатели](../results/current/metrics/avito_text2filter_v2_20261126.json).

## BERT v3 с проверенными метками

Режим `--linker v3` добавляет однозначные варианты для слитного и
разговорного написания марок и моделей, года и объёма двигателя при
распознанной модели. Числа без достаточного контекста, противоречия,
отрицания и словарные коллизии остаются основаниями отказаться от фильтра.

В эксперименте сравниваются три BERT v3 и зафиксированные BERT v2.
Каждый BERT v3 обучается 300 шагов на одинаковом наборе из 80 эталонных
запросов. Одна добавка сохраняет только те решения Qwen о принятии или
отклонении отдельного кандидата, которые подтверждены независимой Astra.
Статус `audited_pairs` хранит принятые варианты в `filters`, проверенные
отрицательные — в `verified_rejections`. Неоценённый вариант пропускается
в обучающем батче. Вторая добавка использует полные ответы Astra на
тех же запросах, которые отобрали из результатов Qwen. В режиме v3
до четырёх дополнительных пар каждого класса берутся без повтора
внутри батча.

Порог контроля и конфигурация для сравнения выбираются на бывшем тесте
v2, выделенном для разработки v3. Критерий сначала максимизирует
минимальное изменение относительно v2 по четырём показателям:
совпадение полных наборов по семействам, то же по трафику, точность
и полнота отдельных фильтров по семействам. Далее применяются сумма
изменений, совпадение по семействам и близость к порогу 0,5. Для
сравнения эффекта дополнительных данных все варианты v3 также
оцениваются при одном пороге контрольного v3. Свежий тест состоит из
80 новых семейств запросов, зафиксированных до обучения.

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v3 train \
  --train "$ASTRA_REFERENCE" --pseudo "$AUDITED_QWEN_PAIRS" \
  --manifest "$RESERVED_FAMILIES" --base "$RUBERT_WEIGHTS" \
  --steps 300 --out "$BERT_V3"
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v3 predict \
  --input "$NEW_TEST_INPUTS" --student "$BERT_V3" --threshold "$DEV_THRESHOLD" \
  --out "$NEW_TEST_PREDICTIONS"
```

Проверенные пары из 83 запросов дали 136 положительных и одну
отрицательную метку Qwen. Выбранный на dev BERT v3 использует порог
0,995. Относительно контроля v2 его полное совпадение наборов фильтров
на 80 новых запросах выросло с 57,60% до 63,45% по семействам и с
51,82% до 80,85% с весом по трафику. Точность и полнота отдельных
фильтров по семействам выросли с 93,65% до 97,83% и с 71,50% до
73,53%. Доля запросов с применённым фильтром снизилась с 54,76% до
52,06%. Одно семейство обеспечило 21,10 п.п. трафикового улучшения.
Оценка выигрыша по семействам имеет парный интервал, включающий ноль.
При общем пороге 0,5 три v3 дали одинаковые метрики на тесте.
Генератор вариантов предложил 80 из 101 эталонного фильтра, v2 — 72.
Распознавание десятичных объёмов может ошибаться при соседней пунктуации
или дополнительных единицах. [Агрегаты](../results/current/metrics/avito_text2filter_v3_20261126.json).

## BERT v4. Линкер и контроль переобучения

Режим `--linker v4` добавляет словарные формы марок и моделей, ограничивает
выбор модели проверяемой связью с маркой и уточняет разбор объёма рядом с
пунктуацией. Защита блокирует числовые альтернативы, проценты и часть
условий об отдельных запчастях. При неоднозначности фрагмент можно
оставить неразобранным. Составные единицы, например расход «л на 100 км»,
и мощность с отделённой запятой единицей остаются краевыми случаями.

Сравнили v3 с двумя вариантами v4: новый линкер с замороженными весами
v3 и тот же линкер с новым обучением на 80 эталонных запросах и 83
запросах с проверенными парами Qwen. Использованы 300 шагов и тот же
seed. По сетке из восьми порогов на бывших тестах v2 и v3 выбрали
замороженные веса и порог 0,995. Критерий сначала максимизировал
минимальную дельту относительно v3 по четырём основным метрикам на
каждой из двух выборок. Тест N4 зафиксировали отдельно до подсчёта.

```bash
python scripts/avito/text2filter.py --archive "$QUERIES_ZIP" --linker v4 predict \
  --input "$N4_INPUTS" --student "$BERT_V3" --threshold 0.995 \
  --out "$N4_PREDICTIONS"
```

На N4, стратифицированной выборке из 80 новых семейств, v3 и выбранный
v4 дали по 54 полных совпадения. Попарно все 80 исходов по полному
совпадению одинаковы. Взвешенные оценки полного совпадения равны
58,45% по семействам и 75,28% по трафику. У v4 точность отдельных фильтров
по семействам снизилась с 97,65% до 97,60%, полнота с 65,29% до 63,87%.
Число эталонных фильтров среди кандидатов снизилось с 75 до 74 из 105.
Линкер отбросил верный объём из-за соседнего нераспознанного сокращения
трансмиссии. В этом запросе полный разбор уже расходился с эталоном у v3.
Переобученный v4 дал 52 полных совпадения, или 53,87% по семействам.
Оценка разницы с v3 составляет −4,58 п.п., 95%-й парный интервал
от −11,45 до 0 п.п. v4 оставлен доступным явно для экспериментов.

Рамка N4 исключает 1 312 семейств из прошлых прогонов и охватывает
44,89% запросов выгрузки. Трафиковая оценка относится к этой рамке.
Из 16 повторно размеченных запросов совпали полные наборы фильтров в
15 случаях. Одно расхождение разобрала отдельная Astra. Границы и причины
неразобранных фрагментов не входили в проверку согласия. [Агрегированные
метрики по всем вариантам](../results/current/metrics/avito_text2filter_v4_20261126.json).

## Пересчёт BX на нормализованном пилоте

Из полученного ZIP извлеките `candidates.parquet` в приватный каталог и
передайте исходный Parquet для строгой сверки. Пилот целиком относится к
test. Для шардов с явной колонкой split предусмотрен `--candidates`.
Для файлов без неё задайте по одному `--candidate-split` на файл.

```bash
python scripts/avito/evaluate_bx_baseline.py \
  --candidate-split test "$NORMALIZED_CANDIDATES" --original "$ORIGINAL_PILOT"
```
