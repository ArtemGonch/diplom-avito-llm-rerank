Слепое сравнение саммари

Сравните два набора наблюдений об одной истории. Источник вариантов скрыт. Для каждого дан одинаковый полный каталог вычисленных фактов.

Оценивайте точность относительно каталога, релевантность, ясность и пользу для понимания ограничений и следующего уточняющего вопроса. Намерение купить и будущий результат по этим данным не известны. Не открывайте основной интерфейс с именами методов или ключ ответов. Один эксперт получает только один набор сравнений.
